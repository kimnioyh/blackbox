# Demo recording checklist

## Before recording

- [ ] PostgreSQL is connected; API and Electron are running.
- [ ] Kiln key is configured locally, without displaying it.
- [ ] Dashboard shows the compliant `VERIFIED`, blocked `BLOCKED`, and disputed `DISPUTED` Cases.
- [ ] Compliant Case `cmumtu7n70000u8yw4v07evjp` is ready.
- [ ] Blocked Case `cmunels8q000cp0yw55p4it62` is ready.
- [ ] Disputed Case `cmumtuehv0007u8yw31ptuymh` shows `VIOLATION` and verified Sepolia proof.
- [ ] The [proof transaction](https://sepolia.etherscan.io/tx/0x935e7762a443f0357885e0b8bdc72073afde68e985636c2395631a3b38a87b96) opens in Etherscan.
- [ ] No private keys, `.env` files, API keys, or recovery phrases are visible.
- [ ] Desktop notifications are disabled and unnecessary terminal windows are hidden.
- [ ] Window size and zoom make policy, checks, and timeline text readable.

## Recording

- [ ] Follow [the final script](final-demo-script.md) in compliant → blocked → disputed → proof → integration order.
- [ ] Record at a readable resolution, with deliberate cursor movement.
- [ ] Show only essential screens; skip long loading waits.
- [ ] Keep the finished video below three minutes, ideally **2:40–2:55**.
- [ ] Do not expose `.env`, API keys, wallet private keys, or secret recovery phrases.

## After recording

- [ ] Check audio, text readability, and video duration.
- [ ] Upload the video to a publicly accessible location.
- [ ] Open the public demo link in an incognito browser to confirm access.
